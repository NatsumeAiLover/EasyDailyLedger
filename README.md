# 日常账本 v1.2

Windows 11 中文个人记账工具，按天记录收支，按月安排预算。采用 C#、WPF 和系统自带 .NET Framework，数据保存在本机，不需要联网或注册。

## v1.2 更新

- 每日账单默认只展开最近一个有账目的日期，其他日期折叠，保留小字号全天收支汇总。
- 点击每天的标题展开或收起；默认从近到远，点击“日期”按钮反转排序。
- 手动展开、收起的状态在本次打开期间保留；重新打开恢复默认。
- 黑灰深色、原墨绿深色、浅色三种主题，自动记住选择。
- 兼容 v1.0、v1.1 账目、分类、预算及备份。

## 构建与检查

在 Windows PowerShell 中，从源码目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
& .\tests\CoreTests.exe
& .\tests\ThemeTests.exe
& .\tests\LedgerTests.exe
```

使用系统自带 .NET Framework 4.x C# 编译器和 WPF 组件，不下载 NuGet 包。执行策略参数只对本次构建进程生效。生成程序在 `发布/日常账本.exe`。

`build.ps1 -OutputDirectory <目录>` 可指定其他输出目录。构建不会改写已有的 `发布/数据`；覆盖程序前请先关闭运行中的同一份程序。

## 目录

- `src/Core.cs`：金额、日期、预算、统计、存储和导出。
- `src/App.cs`：记账、页面操作、分组折叠与日期排序。
- `src/Theme.cs`：三种主题、外观保存和弹窗。
- `src/MainWindow.xaml`：界面与控件样式。
- `src/app.ico`、`src/app.manifest`：图标和程序清单。
- `tests/`：账本核心、主题日历、账单分组的自动检查源码。
- `使用说明.txt`、`升级日志-v1.2.txt`：操作与升级说明。
- `验证记录-v1.2.md`：验证结果与范围。

## 数据与 Git

源码包可直接用于新建 Git 仓库，含 `.gitignore` 和 `.gitattributes`。不包含个人账目、备份、运行日志和编译程序。不要提交自己的 `数据/` 文件夹。

金额使用 decimal 精确到分。保存采用同目录临时文件和原子替换，并保留上一版自动备份；独占锁阻止同一账本并发写入。外观文件与账本分开，切换主题不会改写账目。JSON 完整备份可恢复，CSV 仅供查看。

当前范围为本机、人民币、单账本。数据未加密，程序未商业签名；未在其他电脑验证。不含银行同步、借贷、转账和多设备同步。本仓库尚未指定开源许可证。
