# 日常账本 v1.0

Windows 11 中文个人记账桌面工具，以天为单位记录收支，以月为单位管理预算与统计。采用 C#、WPF 和 .NET Framework，数据保存在本机。

## 功能

- 支出大类、可选备注与补记日期；简化收入记录。
- 月预算、预算余额、收支结余、日均支出与上月同期比较。
- 每日账单分组、搜索筛选、修改删除及分类管理。
- 自动备份、JSON完整备份恢复、中文CSV导出。

## 环境与构建

使用 Windows PowerShell，且系统已提供 .NET Framework 4.x 的 C# 编译器和 WPF 组件。不需要下载 NuGet 包。

在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
& .\tests\CoreTests.exe
```

上面的执行策略参数仅对本次构建进程生效。

生成的程序在 `发布/日常账本.exe`。运行程序不需要编程工具。构建脚本支持64位Windows的系统.NET Framework组件。

## 目录

- `src/`：程序源码、XAML界面、图标和清单文件。
- `tests/`：自动回归检查源码。
- `build.ps1`：离线构建脚本。
- `使用说明.txt`：记账、预算、备份及升级说明。

## 版本说明

这是2026年11月4日发布的1.0源码版本，提供浅色界面。源码从当时的原始编辑记录恢复，保留原版构建脚本。

## 数据与Git

程序旁的`数据/`目录属于个人数据，不应提交到GitHub。源码包不含账目、备份、外观设置、运行日志或已编译程序；.gitignore已排除这些常见输出目录及文件。

金额采用decimal精确到分。保存通过同目录临时文件和原子替换完成，并保留上一版备份；独占锁阻止同一账本并发写入。数据文件未加密。
