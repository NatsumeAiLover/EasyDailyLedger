# 简易记账本 v1.2
- 纯ai跑出来的，以自用为目的，不过发现挺好用，便发上来玩玩，正好学学github，有空再学学编程。
- 此软件为Windows 11 中文个人记账工具，按天记录收支，按月安排预算。采用 C#、WPF 和系统自带 .NET Framework，数据保存在本机，不需要联网或注册。

## v1.2 更新

- 每日账单默认只展开最近一个有账目的日期，其他日期折叠，保留小字号全天收支汇总。
- 点击每天的标题展开或收起；默认从近到远，点击“日期”按钮反转排序。
- 手动展开、收起的状态在本次打开期间保留；重新打开恢复默认。
- 黑灰深色、原墨绿深色、浅色三种主题，自动记住选择。
- 兼容 v1.0、v1.1 账目、分类、预算及备份。
