日常账本 v1.3.0 · Apple 原生版

此版本使用 SwiftUI + Swift Charts + Foundation/AppKit，不附带 Chromium、Node 或 WebKit。
目标：macOS 27、Apple Silicon。应用只需系统组件，首次启动无模拟账目。

安装：解压完整发布包，运行“安装到我的应用.command”。
如果系统拦截脚本，在终端输入 bash 和一个空格，将脚本拖入终端，按回车。
脚本会询问确认，再复制到个人 ~/Applications，不需要管理员密码。
应用已有构建机的 ad-hoc 签名，但未获 Developer ID 签名、未经过 Apple 公证。
安装脚本只处理这一份应用的隔离属性，不改变系统安全设置。

数据：~/Library/Application Support/DailyLedgerNative
原生版使用独立目录，不自动覆盖 Electron 版或 Windows 版账目。
迁移：在旧版导出完整 JSON 备份，到原生版“设置与备份”选择恢复。
恢复会替换当前账本，先自动备份原文件；CSV只用于查看，不能恢复。
Version=1 的 Windows v1.0—v1.3与 Electron 版账本可导入。

首页：记录收入/支出、分类、日期和支出备注。Cmd+S保存当前账目。
设置：管理预算、分类和三种主题。新月沿用最近预算，余额不累加，收入不增加预算。
每日账单：展开日期、筛选、搜索、日期排序、修改及删除。日标题保留全天总额。
支出走势：按日看指定月份，按月看指定年份，可对比上月或上年。
移动鼠标查看详情，点击固定；Tab聚焦图表后用左右方向键选择。
点击查看对应账单，会清除旧筛选并定位当天/当月支出。
没有记录的过去时段按0显示，未来和不存在的日期留空。
当前月仅截至今天，对比虚线保留完整历史期间，不应直接把两者当作同等时长。

金额精确到分，每笔最多1亿元。收入与支出分开统计。
日均按自然天数计算；预算剩余=预算-支出，收支结余=收入-支出，不代表银行卡余额。
数据没有加密或云同步。重要备份请另存到其他磁盘。

验证：GitHub Mac环境负责原生编译、核心检查、签名和打包。

原生文件面板、关闭草稿提示、缩放及macOS 27实际运行。
