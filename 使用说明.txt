日常账本 1.4
按天记录，按月安排。

一、打开与开始
双击同一文件夹里的“日常账本.exe”。首次打开没有模拟账目。
1. 点击“设置预算”，输入本月可支出的总金额。
2. 右侧“记一笔”填写金额和大类；支出备注选填，日期默认今天。
3. 点击保存，首页统计立即更新。也可以按 Ctrl+S 保存当前记账框。
4. 收入只需要金额、大类和日期，不会自动增加预算。

三种外观：浅色、黑灰深色、原墨绿深色。点击左下角按钮依次切换，或到“设置与备份→外观”直接选择。
主题会自动记住；切换配色会保留正在填写的金额、备注和账单筛选。
外观设置保存在“数据/外观设置.json”中，与账目分开。

选择以前的日期：打开日期面板，第一次点击顶部“年月”切到月份选择，
再点击顶部年份可选择其他年份；选年份后再选月份和日期。

二、查看与修改
“每日账单”按日期分组，默认只展开最近一个有账目的日期，其余日期折叠。
每日标题保留小字号的全天支出和收入；点击标题或箭头可展开、收起明细。
日期默认从近到远，点击筛选栏右侧“日期”按钮倒置，再次点击恢复。
手动展开、收起的状态在本次打开期间保留，排序、筛选不重置；重开程序恢复默认。
筛选和搜索时，日期标题仍展示全天收支，底部“当前显示”按筛选结果统计。
可以按类型、大类和搜索词筛选；搜索支持备注、大类、日期。
选中一笔账目后点击修改，或双击账目，返回首页编辑后保存。
删除需要再次确认，删除前版本保存在自动备份中。
顶部切换月份；“本月”按钮回到当前月份。

三、预算和统计
预算剩余 = 本月预算 - 本月支出。负数显示为“已超预算”。
收支结余 = 本月收入 - 本月支出。它不等于银行卡余额。
日均支出：当前月份除以从1日到今天的自然天数，包含今天和未消费的日期。
剩余每天可用：预算剩余除以从明天到月底的天数。
月末最后一天不再除以零；历史月份展示整月汇总。
当前月份与上月相同日期范围比较。如果上月较短，截止到上月最后一天。
历史月份与上月整月比较。没有上期记录时显示暂无；上期为零时不计算百分比。
首次查看新月份时，沿用之前最近一个已设置月份的预算，并单独保存。
已经保存的各月预算互相独立；上月剩余预算不自动累加。
预算可设为0，记账金额必须大于0，最多两位小数，最高1亿元。

四、大类
“设置与备份”中可新增、改名和停用大类。
改名会同步修改历史账目显示的分类名称。
停用保留全部历史记录，可重新启用。每种收支类型至少保留一个启用的大类。

五、保存与备份
数据保存在程序旁的“数据”文件夹中，不连接互联网，不需要账户。
账本.json：当前账本，包含账目、分类和每月预算。
自动备份：每次更改之前的账本快照，不会自动删除。
账本.lock：防止同一个账本被两个窗口同时更改，关闭程序后会释放。
外观设置.json：记住浅色、黑灰或墨绿模式，不属于账目数据。
请不要在程序打开时手动编辑、移动这些文件。

“备份全部数据”生成一个完整JSON备份，可另存到U盘或其他磁盘。
“从备份恢复”会替换当前账本，不做合并；恢复前也会自动保留当前版本。
当前账本损坏时，启动会提示选择有效备份；不会静默清空原账本。
自动备份与账本在同一磁盘，重要数据请另外保存在其他磁盘。
账本是本机普通文件，没有加密或密码锁。

六、CSV 导入、导出与搬家
进入“设置与备份 → CSV 导入与导出”，点击“导入 CSV 数据”或“导出全部 CSV”。
“每日账单 → 导出本月 CSV”导出当前所选月份全部记录，不受筛选影响。

CSV 第一行为表头：日期,收支类别,类别,金额,备注
示例：2026年1月2日,支出,餐饮,25.50,午饭
日期为四位年份、月份和日期不补零；也接受补零中文日期和旧版 yyyy-MM-dd。
收支类别为“支出”或“收入”；金额大于零，最多两位小数，最高1亿元。
类别与软件现有类别按收支分别匹配，未知类别自动加入设置，停用类别重新启用。
类别最多30个字符；备注对应记账界面的备注，最多200个字符，可留空或省略整列。
必需列为日期、收支类别、类别、金额；列顺序不限，其他栏目自动忽略。
支持 UTF-8、带 BOM 的 UTF-16 以及中文 GBK/GB18030；导出使用 UTF-8 BOM。
导入自动识别逗号和制表符分列，兼容“收支类型”表头；无需修改原文件。
本修复版程序版本为1.4.0.1，导出仍使用逗号分列的标准五列表头。
含逗号、双引号或换行的内容须按标准 CSV 写法转义，建议直接使用 Excel 另存为 CSV。

选择文件后，软件先检查整份文件，再显示待导入笔数与类别变化，确认后追加到账本。
重复导入会重复记账，不会自动去重；请确认文件没有导入过。
有格式错误时提示行号，整个文件不导入；取消也不会更改账本。
导入保留原账目和预算，已有账本在导入前自动备份；导入后可切换月份查看。
文本的公式起始符和前导单引号会进行可逆转义，避免 Excel 执行公式；重新导入可恢复原文。

CSV 只包含账目及使用的类别，不包含预算和完整类别配置。
换电脑时：先关闭程序，复制整个程序文件夹（包括 exe 和“数据”文件夹），
也可在另一份程序中恢复 JSON 完整备份。不要只移动 exe 后删除原数据文件夹。

七、使用环境
本版本是免安装的Windows桌面程序，在当前Windows 11电脑上编译验证。
使用Windows的.NET Framework 4.x桌面组件；没有额外的联网服务。
程序文件没有商业代码签名。
建议把整个程序文件夹放在“文档”等你有写入权限的位置。
需要桌面入口时，可右键exe，选择“显示更多选项→发送到→桌面快捷方式”。

此版本不包含银行同步、多设备同步、借贷管理或账户间转账功能。
自己的账户间转账不应重复记为收入或支出。

八、从1.0、1.1、1.2或1.3升级到1.4
先关闭所有日常账本窗口，再用1.4版程序替换原文件夹中的同名exe。
原来的“数据”文件夹继续保留，账目、分类、预算与自动备份可直接使用。
使用说明和升级日志可以一同更新；不需要重新录入或恢复已有账目。
发布压缩包只含程序和说明文件，没有个人账目或模拟数据。

原1.1深色选择升级后对应黑灰深色；如需原绿色，到外观中选择“深色 · 墨绿”。

九、支出走势（1.3新增）
点击左边栏“支出走势”，默认查看本月每天的支出。
“按日”：选择年份、月份，折线上的每个点代表当天支出总额；可打开“对比上月”。
“按月”：选择年份，每个点代表当月支出总额；可打开“对比上年”。
实线代表所选期间，虚线代表对比期间。两条线共用金额坐标，日期/月序号对齐。
对比线保留完整历史期间；本月仅截至今天，不能将本月部分金额直接当作整月金额比较。
没有对比支出记录时提示“暂无对比支出记录”，不绘制虚线、不计算涨跌比例。
鼠标移到绘图区可查看当期与对比期金额、支出笔数；点击位置固定下方详情。
也可用Tab将焦点移到图表，再用左右方向键、Home、End选择日期或月份。
点击“查看对应账单”进入每日账单，按日会定位当天，按月会显示该月支出。
进入账单时会清除原先的分类和搜索条件，并切换为仅支出，方便核对。
过去没有支出记录的日期或月份按0绘图，提示无支出记录，不代表确认当天没有消费。
未来日期、未来月份、不存在的日期留空；不允许切换到未来的年份或月份。
图表仅汇总支出，不以收入抵扣，不修改账目、分类或预算。
走势页的年月与首页独立，本次打开期间保留；重新打开默认本月按日、不打开对比。
并列最高支出显示最早的一天或一个月。新增、修改、删除、恢复账目后重新汇总。
